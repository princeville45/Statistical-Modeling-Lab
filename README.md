# Statistical Modeling Lab

Applied statistical modeling for business — regression, forecasting, segmentation, and predictive analytics. Pure Python, real business context.

This repository contains applied statistical models designed to solve core business problems. Instead of academic datasets, these scripts focus on business-centric logic, from predicting future revenue to identifying high-value customer segments.

## Modules:
. **Revenue Forecasting**: Multi-method forecasting (Moving Average, Exponential Smoothing, Linear Regression).
. **Customer Segmentation**: RFM (Recency, Frequency, Monetary) analysis for marketing prioritization.
. **Regression Analysis**: Multiple linear regression built from scratch using matrix algebra.
. **Anomaly Detection**: Statistical methods for identifying outliers in operational data.

Every model is implemented in clean, standalone Python with a focus on interpretability and business impact.
